### `~/agent` — dual-model local agent (Aug 2026)

Stdlib-only Python REPL against Ollama: `qwen3:8b` orchestrator with a `think_deep` tool that delegates to `qwen3:32b`; tools for shell, read/write file, web fetch, remember/recall; `memory.json` + `context.md` injected into the system prompt.

Lessons for the buddy:

- **Small-orchestrator + big-thinker fits 64GB** (~5 GB + ~20 GB) and keeps simple turns fast. Worth keeping as a routing pattern.
- **Don't hand-roll tool calling.** It used `<tool_call>` JSON in text plus regex repair (missing closing tags, single quotes) — fragile. Ollama's native `tools` API works with Qwen3 (see `docs/mac-studio-local-llm-2026-10-06.md`); use that.
- **Flat key/value memory doesn't accumulate.** After use, `memory.json` held one entry (`name`). Context only grows if structure and a review loop make it happen — supports the product thesis that the context engine, not the chat, is the product.
- **Truncation silently loses context** (`context.md` cut at 2,000 chars, tool output at 3–8k). A real context engine needs retrieval/selection, not truncation.
- **Anti-sycophancy is a wanted trait.** `context.md` was a "critical thinking partner" persona: challenge flawed premises, say "I don't know", push back. Small models needed very emphatic prompting to comply. Carry this into the buddy's default persona.
- **Unsandboxed tools are unacceptable for customers.** Raw `shell=True` and arbitrary file writes with no approval. A sovereign box handling deal documents needs scoped tools, approvals, and an audit trail.

### `~/ralph_loop.sh` + `~/PROMPT_BASE.md` — Ralph loop (Aug 2026)

Bash loop that runs a **fresh headless Claude Code session per iteration** (`claude -p --dangerously-skip-permissions`) on a task file, until the session writes `STATUS.md` = `DONE` / `BLOCKED: <question>` / `CONTINUE`, or a max iteration count is hit.

- Used to build the `ai-marketing-box` dashboard (left `TASK_PROMPT.md`, `TASK_DASHBOARD.md`, `PROGRESS.md`, `run_tests.sh` there); finished with 10 tests passing.
- **What made it work:** no conversation memory — continuity only via `PROGRESS.md` and the code; mandatory `run_tests.sh` before claiming DONE; "same failure twice → change approach or mark BLOCKED"; BLOCKED surfaces one question for the human instead of guessing.
- **Risks:** skips all permission prompts; uses cloud Claude, so it's a build tool, not part of the sovereign product.
- Same principle as this harness and the product: **state lives in inspectable files, not in a model's conversation.**
- If we want this again, recreate it as a harness runbook/tool rather than loose files in the box's home dir.

## Open question: how customers reach their box (discussed, not decided)

User's idea: AWS-hosted platform (frontend + Cognito) that provisions sovereign boxes, then gives each customer a way to reach their box. Undecided whether customers are technical enough for Tailscale/SSH or need an HTTPS dashboard.

Working recommendation:

- **Split control plane from data plane.** AWS hosts signup, billing, provisioning, fleet health — never customer documents or dashboard traffic. Customer data only flows browser ↔ box.
- **TLS must terminate on the box**, not in AWS or Cloudflare. Anything that terminates TLS in the middle (ALB, CloudFront, Cloudflare Tunnel) can read the traffic and breaks the sovereignty story.
- **Cognito as identity, box as resource server:** box validates Cognito-issued JWTs locally against the JWKS, so AWS knows *who* logged in but never sees *what* they see.
- **Default for angel investors (assume non-technical):** HTTPS dashboard at a per-customer URL. Prototype with Tailscale Funnel (TLS ends on the box, `*.ts.net` names only); production via a TCP/SNI-passthrough relay on our domain with certs issued on the box (ACME DNS-01).
- **Advanced option:** Tailscale invite + Tailscale Serve for a private HTTPS URL; SSH only for us/operators, never on the public internet.
- Current dashboards (e.g. ai-marketing-box on 8765) have **no auth** — do not expose them publicly as-is.
